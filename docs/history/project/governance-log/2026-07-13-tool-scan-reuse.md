# 治理变更 2026-07-13 — 铁律7:工具扫盘复用

## 改了什么
`CLAUDE.md` 新增**铁律7**:需要某工具(解压/反编译/调试/构建等)时,先扫全盘找已装的可复用(常见位置 `D:\Tool\`、Program Files、~/scoop、~/.m2、`_tools/`),而非重装或放弃。附**安全铁则**:外来归档/仓库(`D:\src`、Hack.7z)可能含恶意 jar/exe——只读(列表/解压源码/grep),绝不执行陌生可执行文件;大包选择性解压单条目,勿整包(触发 Defender 扫描风暴卡死机器)。

## 时间 / 谁
2026-07-13;本会话。

## dwgx 为什么授权这么改
起因:研究 918 移植时需要 7z 解压 Hack.7z,系统 PATH 无 7z,AI 一度判定"无法处理"。dwgx 指出 `D:\Tool\debugger\Unpackers-Game\7-Zip\7za.exe` 早已存在,并要求规则化:"允许如果需要工具 扫整个电脑 找到可用的工具进行复用"。解决的问题:AI 遇到缺工具时太快放弃/想重装,而 dwgx 的工作站 `D:\Tool` 备了大量现成工具,该先找再用。

## 思维链(为什么这么设计)
- **为何进铁律**:这是跨会话永久工作方式(每次缺工具都适用),属骨架级。
- **为何捆绑安全铁则**:扫盘复用 + 处理外来包是一体两面——刚发生过 Hack.7z(6GB)盲解压触发 Windows Defender 实时扫描风暴、卡死 dwgx 电脑硬重启。所以规则必须同时写死"只读、选择性解压、不执行陌生 exe",否则"能用工具"会诱导 AI 去解压/跑危险内容。
- **未做**:没列举全部工具路径(会僵化);给常见位置 + "自己扫"的判断空间。

## 确认轨迹
CLAUDE.md 改动需 3 次确认(铁律⑤)。dwgx 明确 3 次授权:先"允许...扫整个电脑找可用工具复用",再"我允许 我允许确认确认你 这是两次了可以了吧"(累计 3 次)。本记录即留痕。
